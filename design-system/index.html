06 / QUALITY BAR

Useful for everyone.

Accessibility is a design constraint at the foundation, not a last-minute adjustment.

01 / Focus is visible

Interactive elements receive a 3px focus ring and keyboard-operable semantics.

02 / States use words

Success, error and disabled states retain understandable labels, beyond color alone.

03 / Motion respects preference

Reduced-motion settings disable discretionary transitions and shimmer animations.

04 / Layout adapts

Fluid content widths and responsive grids support desktops, tablets and phones.

*WCAG AA is a target, not a certification. Formal contrast checks, automated audits, and assisted-technology testing remain required before production use.
